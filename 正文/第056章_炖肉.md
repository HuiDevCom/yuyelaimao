# 第056章 炖肉

大橘的炖肉，炖了三天。

第一天，他炖咸了。第二天，他炖淡了。第三天，他把阿月请到他的地下室里，蹲在灶台前，一脸严肃地看着锅里咕嘟咕嘟冒泡的肉："你尝尝。"

阿月尝了一口，嚼了嚼，眼睛亮了："这个好了！"

"真的？"大橘自己也尝了一口，嚼了嚼，表情从紧张到舒展，然后一拍大腿，"好了！出锅！"

他找了一个干净的搪瓷碗，把炖肉盛好，又用一块花布盖住碗口，绑了个结。他抱着碗，站在菜市场门口，深吸一口气，走向小满的豆腐摊。

小满正在整理摊子，看见他抱着一个盖着花布的碗走过来，愣了一下："大橘？"

"给——给你的！"大橘把碗放在她面前，声音有点抖，"我炖的肉！你尝尝！"

"你炖的？"

"嗯！"大橘说，"我炖了三天！今天的最好！我——我给阿白尝过了，她说好吃！"

"阿白？"

"就是——梧桐里七楼那个白头发女孩。"大橘说，"她说好吃，我就——我就拿来了。"

小满低头，揭开碗上的花布，一股肉香飘出来。她看了那碗肉一会儿，拿起筷子，夹了一块，吹了吹，咬了一口，嚼了嚼。

大橘屏住了呼吸。

"……好吃。"小满说，"比菜市场门口那家快餐店的好吃。"

"真的？！"大橘差点跳起来，"那——那——你多吃点！我明天还给你炖！"

"你明天还炖？"

"炖！你爱吃，我就天天炖！"

"你不上班了？"

"上班！"大橘说，"下班了炖！炖肉又不费事！"

小满看着他那副"我明天还给你炖"的认真样子，低头又夹了一块肉，嚼了嚼，说："那你明天少放点姜。"

"好！"大橘掏出手机，认真地记下来，"少放姜。记住了。"

"还有——"小满说，"你别天天送。隔两天送一次就行。天天送，我会长胖。"

"胖了也好看！"大橘脱口而出。

说完，他自己先愣住了。小满也愣住了。两个人隔着一碗炖肉，安静了三秒。大橘的脸涨得通红，结结巴巴地补了一句："我——我是说——胖了——健康！"

"……"小满低头，继续吃肉，没有接话。但她的嘴角，似乎弯了一下。

那天晚上，大橘蹲在阿月家的客厅里，激动得坐不住："她说我炖的好吃！她让我明天少放姜！她还说隔两天送一次！"

"这是好事。"阿月盘腿坐在沙发上，"你离目标，又近了一步。"

"那我下一步怎么办？"大橘搓着手，"我继续送炖肉？"

"送。"林默开口，"但别光送肉。你送完，别急着走，站在那儿，跟她聊两句。"

"聊什么？"

"聊你今天搬了什么货，聊菜市场今天来了什么新鲜菜，聊——"林默想了想，"聊她今天生意怎么样。"

"她今天生意不错！"大橘立刻说，"豆腐卖了一大半！"

"那你就说'今天生意不错啊'——就这么简单。"

"就这么简单？"

"就这么简单。"林默说，"你别一上来就说'我明天还给你炖肉'，你先说'今天生意不错啊'，她回了你，你再接话。一来二去，话就多了。"

大橘听完，一脸佩服："你——你是真懂。阿白，你从哪找的饲主，这么会说话？"

"捡的。"阿月说，"雨夜捡的。"

"那我也去雨夜蹲蹲，看看能不能捡一个——"大橘话说一半，自己先笑了，"我有小满了，不用捡了。"

"你还没追到呢。"阿月泼冷水。

"快了！"大橘自信满满，"等我的炖肉吃到第十碗，她就是我的了！"

阿月看着他自信满满的样子，忽然觉得，大橘这种盲目乐观，也挺可爱的。她转头，看了看林默——他正低头喝茶，嘴角带着一点笑意。

她忽然想：她的炖肉，什么时候才到第十碗？
