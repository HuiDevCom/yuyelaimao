# 第021章 发烧

钥匙是周二丢的。

那天早上，林默收拾出门的东西——他约了客户见面，难得要出趟门。他翻遍了玄关的鞋柜、茶几、外套口袋，都没找到钥匙。他蹲在地上，把沙发底下都摸了一遍，没有。

"钥匙呢？"他嘀咕，"我昨晚还用了。"

"你昨晚回来的时候，在楼下停了一会儿。"女孩蹲在纸箱边，说，"你掏手机的时候，有东西掉了。我听见声音了。"

"你听见了？"

"嗯。"她说，"金属落地的声音。在便利店门口那棵梧桐树那边。"

"那我去找找。"林默站起来，"你先吃早饭。"

"我去吧。"女孩说，"你约了客户，别迟到。"

"外面下雨呢。"

"下雨怎么了。"她说，"我又不怕——"她说到一半，改口，"我打伞。"

"……"

"你等我一会儿。"她说着，已经套上那件旧外套，拿起王姨给的蓝伞，开门出去了，"十分钟就回来！"

林默站在门口，听着她的脚步声轻快地下了楼，心里忽然有点不踏实。他看了看时间，客户约的十点，还来得及。他坐下来，等她。

十分钟过去了。二十分钟。三十分钟。

雨越下越大。林默站在窗边，看着楼下的梧桐树——雨幕里，梧桐树的叶子被浇得翻白，路面上的水洼泛着光。没有那把蓝伞。

他坐不住了。他拿上另一把伞，冲下楼。

雨很大。林默沿着梧桐街找过去——便利店门口，没有；梧桐树下，没有；面馆门口，没有。他一路找，一路喊，喊到嗓子发哑。雨声把他的声音吞得一干二净。

最后，他在街角的水沟边找到了她。

她蹲在那里，浑身湿透——伞歪倒在一旁，被风吹得滚了老远。她的白头发贴着脸颊，雨水顺着发梢往下淌。她低着头，正用两只手，在水沟的雨水里捞着什么。

"你干什么！"林默冲过去，一把把她拉起来，"你疯了吗！"

"钥匙！"她抬起头，脸上全是水，分不清是雨还是别的，"我看见它掉进去了！就在底下！我够得着——"

"一把钥匙！"林默吼她，"一把钥匙你淋成这样！你是不是傻！"

她被吼得愣住了。她站在雨里，看着他，忽然小声说："那是你家的钥匙。"

"钥匙可以配！丢了就丢了！"

"不能丢。"她说，"那是你家的钥匙。你家……你家的门，只能你和我进。配一把，就不是原来那把了。"

林默站在雨里，张着嘴，忽然什么话都说不出来了。雨水顺着他的脸颊流下来。他看了她好一会儿，然后弯下腰，把手伸进冰凉的雨水里，摸到了那把钥匙——它卡在水沟的篦子缝里，差一点就要被冲走。

他把钥匙攥在手里，直起身。她看着他手里的钥匙，笑了："找到了！"

"嗯。"林默把钥匙收进口袋，然后脱下自己的外套，不由分说地罩在她头上，"走，回家。"

"我自己——"

"别说话。"他说，"回家。"

回家的路上，雨还在下。林默撑着伞，她缩在他的外套底下，两个人都湿透了。走到楼下的时候，她打了第一个喷嚏。

"阿嚏！"

林默的心沉了一下。他加快脚步，上楼，把她推进浴室："洗热水澡。泡到头发热了再出来。"

"我没事——阿嚏！"

"进去！"

她缩进浴室，关上门。林默站在门口，听着里面传来哗啦啦的水声，转身去厨房烧姜汤。

姜汤煮好的时候，她出来了——穿着他的旧T恤，头发湿漉漉的，脸色有点白。她接过姜汤，喝了一口，皱起眉："辣。"

"姜汤都辣。喝完。"

"嗯。"她小口小口地喝完，把碗递给他，"喝完了。那我——阿嚏！"

第二个喷嚏。第三个。第四个。

林默伸手，摸了摸她的额头——烫的。他收回手，说："发烧了。"

"猫都不发烧——阿嚏！"

"你不是猫。"林默说，"你是淋了雨的人。"他顿了顿，"去躺着。"

"我——"

"去躺着。"他说，"这是命令。饲主的命令。"

她看着他，张了张嘴，最终没反驳。她乖乖地钻进纸箱——林默看不下去，把她从纸箱里拎出来，塞进沙发，盖上毯子："生病了睡箱子，是想把自己裹成猫卷吗？"

"……猫卷也挺好。"她缩在毯子里，只露出一双眼睛，瓮声瓮气地说。

林默没理她。他搬了把椅子，坐在沙发边，打开电脑，工作——但他一个字也画不进去。他每隔五分钟就摸一次她的额头。额头越来越烫。

傍晚，她的脸烧得通红，人已经开始迷糊了。她缩在毯子里，一会儿喊冷，一会儿喊热，一会儿又说胡话——声音很轻，断断续续的，林默凑近了，才听清她在说什么。

"……别赶我走。"

"我听话。"

"……我吃很少的。真的。"

林默的手顿住了。他蹲在沙发边，看着烧得迷迷糊糊的她，忽然觉得胸口被什么东西狠狠攥了一下。他不知道她梦见了什么——是哪个雨夜，哪条街，哪扇关上的门。

他伸手，轻轻擦掉她额角的汗，低声说："不赶你走。"

"……"

"听见没有？"他说，"不赶你走。你爱住多久，住多久。"

她没有回应，但她的眉头，好像松了一点。她翻了个身，把脸埋进毯子里，呼吸慢慢平稳下来。

林默坐在沙发边，看着她烧红的脸，忽然想起那个雨夜——他蹲在垃圾桶旁，把外套罩在一只白猫身上。他那时候不知道，他罩住的，是一个会在他发烧时说"我吃很少的"的、怕被赶走的人。

他摸了摸她的额头，还是烫的。他站起来，去卫生间拧了一条凉毛巾，敷在她额头上。

"快点好起来。"他说，"好了，我带你去买鱼干。"

"……"她烧得迷迷糊糊，却像是听见了，含含糊糊地应了一声，"嗯……"

窗外的雨，下了一整夜。
