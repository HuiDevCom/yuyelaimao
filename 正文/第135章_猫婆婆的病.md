# 第135章 猫婆婆的病

猫婆婆病倒的消息，是周医生打电话告诉阿月的。

那天早上，阿月正在杂货铺门口扫雪，手机响了。她接起来，周医生的声音很平静："阿月，猫婆婆昨晚发烧了。我给她打了针，烧退了，但她的身体——不太好了。"

阿月握着手机，蹲在雪地里，没有说话。

"你要是方便，过来看看她吧。"

"我马上来。"

她挂了电话，把扫帚靠在墙边，往周医生的诊所跑去。一路上雪很滑，她跑得急，差点摔了一跤。她推开门的时候，看见猫婆婆躺在诊所内室的床上，盖着被子，闭着眼，呼吸很浅。

"猫婆婆。"她蹲在床边，轻声喊。

猫婆婆睁开眼——两只灰蒙蒙的眼睛，看着天花板的方向，没有焦距。她听见阿月的声音，嘴角动了一下："阿白？"

"是我。"

"你怎么来了？周医生告诉你的？"

"嗯。"

"他多事。"猫婆婆说，"我没事，就是有点发烧。"

阿月蹲在床边，握着猫婆婆的手——枯瘦的，凉凉的，骨节分明。她没说话，就那么握着。

"阿白，旧城下雪了吗？"

"下了。"阿月说，"昨天晚上下了一夜，积了厚厚一层。"

"老周走的那年，也下了一场大雪。"猫婆婆说，声音很轻，像在回忆很久以前的事，"他走在雪地里，去给一只猫看病，回来就病了。后来，就没好过。"

阿月握着她的手，没有说话。

"我活了快一百年了。"猫婆婆说，"我见过的人，送走的猫，比旧城的落叶还多。我没什么遗憾了。"她顿了顿，"唯一的遗憾，就是没能亲眼看见，你把旧城守下去。"

"您不用亲眼看见。"阿月说，"您听得到。您听周医生给您念信，听我给您打电话，听小七在信里写'我学会写月字了'——您听得到，就够了。"

猫婆婆躺在床上，嘴角弯了一下："嗯。我听得到。"

那天，阿月坐在猫婆婆床边，坐了一整天。傍晚的时候，猫婆婆睡着了，呼吸平稳了一些。阿月站起来，走到门口，对周医生说："周医生，她还有多久？"

周医生沉默了一会儿，说："不好说。可能几天，可能一个月。她的身体，像一盏油灯，油快尽了，但灯芯还在撑。"

阿月蹲在诊所门口，看着雪地上的暮色，忽然说："那我天天来。她把油烧完之前，我陪着她。"

[卷四·第135章 完]
